부족하다고 나온 항목에 맞춰 소개글·키워드·답글·소식 글감을 바로 만들어 드립니다.

입력은 다 끝났습니다

1 플레이스 정보 전부 자동

업체명·지역·업종·가격은 네이버에서 그대로 가져옵니다. 손댈 필요 없습니다. 값이 틀렸을 때만 고치세요. (자동 수집이 안 되는 휴대폰 단독 사용 시에는 여기가 유일한 입력 경로입니다.)
보유 시설도 네이버 편의시설에서 자동으로 켭니다. 네이버에 안 적힌 시설만 직접 켜 주세요.

보유 시설 · 서비스
체크한 항목이 소개글·대표키워드 생성에 쓰입니다.

2 목표 키워드 사장님만 정할 수 있음

이 칸이 왜 있나요? 소개글은 자동으로 가져옵니다. 하지만 목표 키워드는 가져올 수 없습니다 — "어떤 말로 검색됐을 때 1등이 되고 싶은지"는 플레이스에 적혀 있지 않고 사장님 머릿속에만 있기 때문입니다. 그래서 일단 등록된 대표키워드로 채워 두었고, 다른 키워드를 노리신다면 여기서 바꾸시면 됩니다.

목표 키워드 (최대 3개) *
1순위 키워드부터 넣으세요. 띄어쓰기는 있어도 없어도 됩니다.

3 진단 실행 버튼만 누르면 됨

여기서 하실 일은 버튼 하나입니다. 아래 22개 목록은 채점 기준 전체를 그대로 펼쳐 둔 것이고, 대부분 자동으로 채워집니다. 손으로 체크할 항목은 진단 결과 안에서 바로 체크하실 수 있으니 여기까지 내려오실 필요 없습니다. 기준을 확인하고 싶을 때만 펼쳐 보세요.

🔗 도우미 서버 서버 연결됨

위 검색줄의 수집, 그리고 순위 조회 · 상위 3곳 분석이 이 서버를 씁니다.

📱 휴대폰에서도 이 기능을 쓰려면

같은 와이파이에 연결한 뒤, 휴대폰 브라우저에 아래 주소를 입력하고 북마크해 두세요. 한 번만 하면 그다음부터는 북마크만 누르면 됩니다.

💡 지금은 수동 입력 모드

이대로도 진단·키워드 분석·문장 생성은 전부 됩니다. 아래 3가지만 PC의 도우미 프로그램이 필요합니다 — 네이버에 직접 요청을 보내야 해서 브라우저 혼자서는 막혀 있습니다.

  • 플레이스 정보 자동 수집 (리뷰수·사진수·저장수)
  • 목표 키워드 순위 조회 및 추적
  • 상위 3곳 경쟁 분석
📋 휴대폰에서 지금 바로 — 위 "네이버 화면 붙여넣기"를 쓰세요

네이버 지도에서 내 가게 페이지 텍스트를 복사해 붙여넣으면 리뷰수·사진수·저장수·시설·가격·소개글을 찾아내 자동으로 채웁니다. 서버가 필요 없습니다.

💻 PC에서 — 한 번만 설정하면 그다음은 자동입니다

내려받은 폴더에서 시작하기 파일을 더블클릭하세요. 명령어를 칠 필요 없습니다.
· 윈도우 → start.bat　· 맥 → start.command
브라우저가 알아서 열리고, 위 3가지 버튼이 나타납니다. PC를 켤 때마다 자동 실행되게 하는 방법은 README에 있습니다.

📱 휴대폰에서 — PC가 켜져 있으면 폰에서도 됩니다

PC에서 도우미를 켜면 화면에 휴대폰용 주소가 나옵니다. 같은 와이파이에서 그 주소로 한 번 들어가 북마크해 두면, 이후로는 폰에서도 자동 수집·순위·경쟁 분석이 전부 됩니다.

📋 네이버 화면 붙여넣기 서버 불필요

네이버 지도에서 내 가게 페이지를 열고 → 화면 텍스트를 전체 선택해 복사 → 여기 붙여넣기. 리뷰수·사진수·저장수·시설·가격·소개글을 찾아내 자동으로 채웁니다. 소개글만 복사해 넣어도 됩니다.

💾 저장 내역 기기 상관없이 보임

진단한 시점을 남겨 둡니다. 같은 가게는 가장 최근 것 하나만 남습니다. 소개글이나 사진을 고치기 전에 한 번 저장해 두면 나중에 점수가 얼마나 움직였는지 보입니다.
