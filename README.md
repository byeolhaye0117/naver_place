# 헬스장 플레이스 진단 도구

헬스장·피트니스 센터 전용 네이버 플레이스 진단 도구입니다.
**네이버가 순위를 매기는 3개 축(적합도 · 인기도 · 거리)** 구조로 진단하고,
목표 키워드가 실제로 매칭되는지 계산하며, 원하면 **현재 순위까지 추적**합니다.

개인 운영용입니다. 외부 공개나 상담 유도 기능은 없습니다.

```
index.html   진단 도구 본체 (단독 실행 가능)
server.js    로컬 서버 — 자동 수집 · 순위 추적 · AI 프록시 (선택)
```

---

## PC · 휴대폰 함께 쓰기

| | 휴대폰 | PC (서버 실행 시) |
|---|---|---|
| 진단 · 키워드 분석 · 문장 생성 | ✅ | ✅ |
| 플레이스 자동 수집 | ❌ | ✅ |
| 순위 조회 · 추적 | ❌ | ✅ |
| 상위 3곳 경쟁 분석 | ❌ | ✅ |

**입력값은 기기마다 자동 저장**됩니다(localStorage). 새로고침해도, 며칠 뒤 다시 열어도 그대로입니다.

**기기를 옮길 때**는 페이지 하단 `다른 기기로 이어서 하기`에서:

1. 보내는 기기 — `코드 만들어 복사` → 카카오톡 '나에게 보내기'에 붙여넣기
2. 받는 기기 — 그 코드를 칸에 붙여넣고 `코드 불러오기`

업체명·지역·키워드·소개글·시설·체크 상태가 전부 그대로 넘어갑니다.
서버 없이 동작하므로 휴대폰↔PC, 집↔매장 어디서든 됩니다.

**다크 테마**는 기기 설정을 따라갑니다. 밤에 폰으로 봐도 눈이 편합니다.

## 두 가지 실행 방법

### A. 수동 모드 — 설치 없음

`index.html`을 더블클릭해서 브라우저로 엽니다. 휴대폰에서도 그대로 씁니다.
진단·키워드 분석·문장 생성은 전부 됩니다.

### B. 서버 모드 — 자동 수집 + 순위 추적 + 경쟁 분석

```bash
node server.js
```

브라우저에서 `http://localhost:5173` 접속. Node 18 이상이면 됩니다.
**npm install 불필요** — 외부 의존성이 하나도 없습니다.

서버가 켜져 있으면 페이지 상단에 `자동 수집 · 순위 추적` 패널이 자동으로 나타납니다.

| 기능 | 설명 |
|---|---|
| 정보 자동 수집 | 플레이스 주소만 넣으면 업체명·소개글·리뷰수·사진수·저장수를 가져와 입력란을 채웁니다 |
| 순위 조회 | 목표 키워드로 검색했을 때 내 가게가 몇 위인지 조회합니다 |
| 순위 추적 | 조회할 때마다 `data/rank-history.json`에 기록되고, 직전 대비 ▲▼ 변동을 표시합니다 |
| **상위 3곳 분석** | **상위권이 왜 뜨는지 분석하고, 우리가 뭘 해야 하는지 뽑아냅니다** |
| AI 프록시 | API 키가 서버에만 있고 브라우저로 내려오지 않습니다 |

### 상위 3곳 분석 — 이 도구의 핵심

목표 키워드로 검색해 **상위 3곳을 실제로 수집·비교**합니다.

**1. 지표 비교 + 3위 진입선**

| 지표 | 우리 | 1위 | 2위 | 3위 | 3위 진입선 |
|---|---:|---:|---:|---:|---|
| 방문자 리뷰 | 41개 | 312 | 268 | 190 | **149개 부족** |
| 사진 | 12장 | 88 | 64 | 52 | **40장 부족** |

상위 3곳 중 **가장 낮은 값**이 곧 3위 진입선입니다. 막연한 "많이 채우세요"가 아니라 숫자로 나옵니다.

**2. 상위권이 공통으로 쓰는데 우리에겐 없는 표현**

헬스장 도메인 어휘 사전(시설·프로그램·운영조건·대상·기구·신뢰 6개 범주)으로
상위권 소개글을 훑어, **2곳 이상이 쓰는데 우리에겐 없는 표현**을 뽑습니다.

> 누락: 무료주차(3/3곳), 샤워실(3/3곳), 24시간(3/3곳), 무료체험(3/3곳), PT, 락커, 운동복 …

`무료주차`가 잡히면 `주차`는 자동으로 흡수해 목록이 부풀지 않습니다.

**3. 거리 추정**

네이버의 실제 검색 좌표는 알 수 없지만, **상위권이 몰려 있는 지점이 그 키워드의 중심**입니다.
상위 3곳 좌표의 중심을 검색 중심으로 잡고 우리 거리를 잽니다.

**4. 결론 — 반드시 3개로 나눕니다**

여기가 이 기능의 핵심입니다. 격차를 뭉뚱그리면 실행할 수 없는 목록이 됩니다.

| 분류 | 내용 |
|---|---|
| 🟢 오늘 할 수 있는 것 | 소개글 길이, 누락 표현 추가, 사진 업로드 |
| 🟡 시간이 걸리는 것 | 리뷰·저장·평점 — 몇 주~몇 달. 구매는 제재 대상 |
| ⚪ 바꿀 수 없는 것 | 거리. 이 경우 **다른 키워드로 목표를 바꾸라고** 조언합니다 |

AI를 쓰려면 키를 환경변수로 넣고 서버를 켜세요:

```bash
ANTHROPIC_API_KEY=sk-ant-... node server.js
```

## 진단 구조 — 네이버 3축

| 축 | 배점 | 통제 가능성 | 의미 |
|---|---:|---|---|
| **적합도** | 45 | 100% 통제 가능 | 검색어와 내 정보가 매칭되는가. 노출될 **자격**을 만드는 축 |
| **인기도** | 40 | 간접 유도만 | 클릭·체류·저장·리뷰. 유발 장치(사진·답글·소식)만 통제 가능 |
| **거리·신뢰** | 15 | 통제 가능 | 핀 좌표 정확도. 헬스장은 거리 가중치가 특히 큼 |

각 항목에는 **통제 유형**이 표시됩니다.

- `직접통제` — 오늘 바로 바꿀 수 있는 것
- `간접유도` — 손님 행동을 유발하는 장치
- `결과지표` — 손님이 만드는 결과 (억지로 만들면 제재 대상)

### 적합도는 체크가 아니라 계산입니다

22개 항목 중 **4개는 자동 채점**됩니다. 목표 키워드와 소개글을 넣으면:

- 키워드가 소개글·업체명·대표키워드에 실제로 있는지 **토큰 단위로 매칭**
- 구문 전체 매칭 / 부분 매칭 / 약한 매칭 / 매칭 없음 판정
- 단어별 출현 횟수와 위치 표시
- **과다 반복 감지** — 12회 이상이거나 밀도 6% 초과(300자 이상일 때)면 어뷰징 경고
- **업체명 키워드 스터핑 감지** — 지역·업종어가 2개 이상 박혀 있으면 경고

### 병목 축 진단

세 축 중 가장 낮은 축을 지목하고, 왜 그 축이 발목을 잡는지 인과 사슬로 보여줍니다.

```
정보 채우기 → 검색 후보 진입 → 거리 필터 통과 → 노출 → 클릭·체류·저장 → 순위 상승
```

세 축이 모두 80% 이상이면 병목 대신 "뚜렷한 병목 없음"으로 안내합니다.

## 네이버 응답이 깨졌을 때

네이버는 공개 API가 없고 내부 응답 구조를 예고 없이 바꿉니다.
그래서 이 서버는 **경로를 고정해 파싱하지 않고**, 여러 엔드포인트를 순서대로 시도한 뒤
응답 트리 전체를 훑어 **필드 이름으로 값을 주워담습니다.** 구조가 바뀌어도 잘 버팁니다.

그래도 깨지면 점검 명령으로 원인을 확인하세요:

```bash
node server.js --probe "강남역 헬스장" "https://map.naver.com/p/entry/place/1234567890"
```

API 엔드포인트:

| 경로 | 설명 |
|---|---|
| `/api/place?url=` | 플레이스 정보 수집 |
| `/api/rank?keyword=&url=` | 순위 조회 (자동 기록) |
| `/api/competitors?keyword=&url=&top=3` | 상위 N곳 경쟁 분석 |
| `/api/history?keyword=` | 순위 기록 조회 |
| `/api/ai` | Claude 프록시 (POST) |

어떤 엔드포인트를 시도했고 각각 어떻게 실패했는지 전부 출력됩니다.
그 출력을 그대로 알려주시면 파서를 맞출 수 있습니다.

> **참고** — 개발 환경의 네트워크 정책상 네이버 접속이 차단되어 있어,
> 수집·순위 로직은 응답을 흉내 낸 테스트로만 검증했습니다.
> 실제 네이버 응답에 대한 첫 검증은 사장님 PC에서 위 `--probe`로 하셔야 합니다.

## 이 도구가 하는 일과 못 하는 일

**하는 일** — 통제 가능한 항목의 누락을 찾아냅니다.
매일 보느라 안 보이던 빈칸을 남의 눈으로 훑어주는 것, 그리고 목표 키워드가
실제로 매칭되는지 계산해주는 것이 핵심 가치입니다.

**못 하는 일** — 네이버 점수를 알려주지 못합니다.
네이버는 순위 알고리즘을 공개하지 않습니다. 여기 나오는 점수는 네이버 점수가 아니라
**공개된 노출 원리를 바탕으로 만든 체크리스트의 점수**입니다.
적합도는 입력값으로 실제 계산하지만, 인기도·거리는 자가 체크 기반입니다.

정보를 채운다고 순위가 오르는 게 아닙니다.
**채워야 노출될 자격이 생기고 → 노출돼야 클릭이 생기고 → 클릭이 쌓여야 순위가 오릅니다.**
이 도구는 그 출발선에 서게 해주는 역할입니다.

리뷰·저장수 구매 같은 어뷰징은 네이버가 갈수록 정교하게 잡아냅니다. 권하지 않습니다.
