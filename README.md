# 헬스장 플레이스 진단 도구

헬스장·피트니스 센터 전용 네이버 플레이스 자가진단 웹페이지입니다.
22개 항목을 체크하면 100점 만점 점수, 개선 액션, 복붙용 소개글·키워드·리뷰답글이 나옵니다.

파일은 `index.html` 하나뿐입니다. 서버도, 빌드도, 설치도 필요 없습니다.

---

## 1. 내 정보로 바꾸기

`index.html`을 열어 `CONFIG` 부분만 고치면 됩니다. (`<script>` 시작 부분, 위에서 찾기 쉽습니다)

```js
const CONFIG = {
  centerName: "우리 센터",                 // 센터 이름
  tel: "010-0000-0000",                    // 전화 상담 번호
  kakaoUrl: "https://open.kakao.com/",     // 카톡 오픈채팅 링크
  ctaText: "플레이스 세팅부터 소개글·사진 구성까지 같이 잡아드립니다."
};
```

시설 목록을 바꾸려면 바로 아래 `FACILITIES` 배열을 수정하세요.

---

## 2. 배포하기 (GitHub Pages · 무료)

1. GitHub 저장소 → **Settings** → 왼쪽 메뉴 **Pages**
2. Source를 **Deploy from a branch**로 두고, 브랜치를 이 브랜치로 선택 → Save
3. 1~2분 뒤 `https://<계정명>.github.io/development_place/` 로 접속

---

## 3. 진단 항목 구성

| 영역 | 배점 | 항목 수 | 성격 |
|---|---:|---:|---|
| 적합도 — 검색어에 걸리는가 | 40점 | 8 | 사장님이 100% 통제 가능 |
| 시각 정보 — 이탈을 막는가 | 25점 | 5 | 사장님이 100% 통제 가능 |
| 인기도 — 손님 행동이 쌓이는가 | 25점 | 6 | 간접 유도만 가능 |
| 위치 · 신뢰 | 10점 | 3 | 핀·인증은 통제 가능 |

배점이나 항목을 바꾸려면 `ITEMS` 배열을 수정하세요.
각 항목은 `w`(배점), `t`(항목명), `why`(왜 중요한지), `act`(미달 시 할 일)로 구성됩니다.
배점 합계가 100이 되도록 맞춰야 점수가 정확합니다.

---

## 4. 관리자 모드 (Claude AI 소개글 생성)

4단계 하단의 `⚙️ 관리자 모드`를 열면 Claude API로 소개글을 다시 쓸 수 있습니다.

> **공개 페이지에서는 사용하지 마세요.**
> 브라우저에서 API를 직접 호출하는 방식이라 **키가 방문자에게 노출됩니다.**
> 사장님 본인 PC에서만 쓰시고, 키는 브라우저 탭에만 임시 저장됩니다(코드·서버에 저장 안 됨).
> 공개 페이지에서 AI 생성이 필요하면 키를 숨길 중계 서버가 따로 있어야 합니다.

사용 모델: `claude-opus-5`

---

## 5. 이 도구가 하는 일과 못 하는 일

**하는 일** — 사장님이 통제할 수 있는 항목의 누락을 찾아냅니다.
매일 보느라 안 보이던 빈칸을 남의 눈으로 훑어주는 것이 이 도구의 핵심 가치입니다.

**못 하는 일** — 네이버 점수를 알려주지 못합니다.
네이버는 순위 알고리즘을 공개하지 않습니다. 여기 나오는 점수는 *네이버 점수가 아니라
이 체크리스트의 점수*입니다. 또한 클릭·체류시간·재방문 같은 실제 이용자 행동 데이터는
사장님도, 어떤 도구도 정직하게는 만들 수 없습니다.

정보를 채운다고 순위가 오르는 것이 아니라, **채워야 노출될 자격이 생기고 → 노출돼야 클릭이 생기고
→ 클릭이 쌓여야 순위가 오릅니다.** 이 도구는 그 출발선에 서게 해주는 역할입니다.

리뷰·저장수를 구매하는 어뷰징은 네이버가 갈수록 정교하게 잡아냅니다. 권하지 않습니다.
